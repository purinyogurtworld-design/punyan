# プリンワールド ブラウザ版 0.12.12（テスト用）

https://purinyogurtworld-design.github.io/punyan/play/ を開くと遊べます。

- パソコンの Chrome か Edge でどうぞ（スマホ・タブレットでもタップで操作できます）。
- 最初に読み込むのは約 22 MB（エンジン・タイトル・名前入力・章選択）だけです。ふつうの回線なら 10 秒ほどでタイトルが出ます。
- 残りのデータは、タイトルが出た瞬間から裏で読み込みます（画面には出しません）。物語で先に使う順に並べてあるので、第一章が始まってもそのまま進めます。回線がとても遅くて間に合わないときだけ、右下に「つづきを準備しています…」が少し出ます。
- 冒険の記録はそのブラウザに残ります（別のブラウザやPCには引き継がれません）。

## 画面内コントローラー

タイトル画面からすべての画面に表示されます。タップ・クリックで操作でき、ゲームパッドやキーボードのボタンを押すと同じボタンが光ります（連動）。タイトルの「設定 → 画面内コントローラー」で非表示にもできます。

- 町とダンジョンでは、その場面用のコントローラー（地図・装備・道具・メニュー／剣技など）が出ます。
- それ以外の画面（タイトル・名前入力・章選択・プロローグと物語の会話・メニュー・お店・図鑑・確認ダイアログなど）では「移動・戻る・アクション」が出ます。
- 会話の画面では、会話の枠をコントローラーの間に収めているので重なりません。メニュー画面では少し薄く表示し、画面のボタンと重ならない位置にボタンを寄せています。重なった所をタップしたときは、画面のボタンが優先されます。

| 場面 | ボタン |
|---|---|
| タイトル・名前・章選択 | 移動（選択） / 戻る ○ / アクション ×（決定） |
| 町 | 地図 □ / 装備・道具 △ / メニュー OPTIONS / 移動 L / 戻る ○（建物から出る） / アクション ×（話す・調べる・入る） |
| ダンジョン | メニュー OPTIONS / 装備・道具 / 地図 タッチパッド / 移動 / 突き △ / 回転斬り R1 / 奥義 R2 / 斬撃 □ / 回避 ○ / 回復 L1 / 護符 L2 / 調べる × |
| 会話 | × 次へ / 十字キー← 読み返す / ○ 中断（画面の「次へ」「会話を中断」もタップできます） |

キーボード：町は E アクション / BackSpace 戻る / M 地図 / I 装備・道具 / Esc メニュー、ダンジョンは J 斬撃 / K 突き / L 回転斬り / U 奥義 / Space 回避 / Q 回復 / F 護符 / E 調べる / M 地図 / I 装備・道具 / Esc メニュー。
