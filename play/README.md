# プリンワールド ブラウザ版 0.12.14（テスト用）

https://purinyogurtworld-design.github.io/punyan/play/ を開くと遊べます。

- パソコンの Chrome か Edge でどうぞ（スマホ・タブレットでもタップで操作できます）。
- 最初に読み込むのは約 22 MB（エンジン・タイトル・名前入力・章選択）だけです。ふつうの回線なら 10 秒ほどでタイトルが出ます。
- 残りのデータ（約 400 MB）は、タイトルが出た瞬間から裏で読み込みます（画面には出しません）。第一章の物語は使う順に並べてあるので、そのまま進めます。
- ダンジョン・メニュー・お店・号外・つづきから など、中身が記録や冒険ごとに変わる場面は、全部のデータが届いてから始まります。まだ届いていないときは「つづきを準備しています… x / y MB」が出て、届いたらそのまま始まります（届く前のデータを使うとブラウザが止まってしまうため。宝箱を開けたときのフリーズはこれが原因でした）。
- 冒険の記録はそのブラウザに残ります（別のブラウザやPCには引き継がれません）。

## 画面内コントローラー

タイトル画面からすべての画面に表示されます。タップ・クリックで操作でき、ゲームパッドやキーボードのボタンを押すと同じボタンが光ります（連動）。タイトルの「設定 → 画面内コントローラー」で非表示にもできます。

- 町とダンジョンでは、その場面用のコントローラー（地図・装備・道具・メニュー／剣技など）が出ます。
- それ以外の画面（タイトル・名前入力・章選択・プロローグと物語の会話・メニュー・お店・図鑑・確認ダイアログなど）では「移動・戻る・アクション」が出ます。物語や町の人・係員・コトリとの会話の間は「戻る」は出ません（移動とアクションだけ）。
- 大きさはどの画面でも同じ（町と同じ大きさ・同じ位置）です。
- 会話の画面では、会話の枠をコントローラーの間に収めているので重なりません。メニュー画面や、タイトルの上に開く窓では、コントローラーを薄く重ねて表示します。重なった所をタップしたときは、画面のボタンが優先されます。

| 場面 | ボタン |
|---|---|
| タイトル・名前・章選択 | 移動（選択） / 戻る ○ / アクション ×（決定） |
| 町 | 地図 □ / 装備・道具 △ / メニュー OPTIONS / 移動 L / 戻る ○（建物から出る） / アクション ×（話す・調べる・入る） |
| ダンジョン | メニュー OPTIONS / 装備・道具 / 地図 タッチパッド / 移動 / 突き △ / 回転斬り R1 / 奥義 R2 / 斬撃 □ / 回避 ○ / 回復 L1 / 護符 L2 / 調べる × |
| 会話 | × 次へ / 十字キー← 読み返す（画面の「次へ」もタップできます。会話を途中でやめるボタンはありません） |

## カーソル（十字キー・左スティック）

すべてのメニュー・お店・図鑑・タブ・確認ダイアログ・タイトル・名前入力・章選択に、光る枠と◆のカーソルが出ます。十字キー（または左スティック・矢印キー）でカーソルを上下左右に動かし、×（Enter）で決定、○（Esc）で戻ります。タブ（武器・防具・道具…）もカーソルで選べるので、ゲームパッドだけで最初から最後まで遊べます。L1 / R1 はページ送りです。

## セーブ

- セーブできるのは次の 3 つだけです。
  1. 町の噴水の女神像に話しかけて「保存する」
  2. ダンジョンを踏破したとき（自動保存）
  3. ダンジョンで力尽きたとき（自動保存）
- それ以外（買い物・装備の変更・ガチャ・物語の進行・ダンジョンの途中など）は、次にセーブするまでブラウザの中にだけ残ります。セーブせずに閉じると、最後にセーブしたところから始まります。
- ダンジョンの途中では保存しません（冒険メニューの「冒険を保存」はなくなり、「ゲームを終了」になりました）。歩いている途中や宝箱を開けたときに保存処理が走らないので、引っかかりもありません。

## そのほか

- ダンジョンは挑戦するたびに部屋のつながり・入口・階段の位置が変わります（「再挑戦」でも新しい迷宮になります）。
- 剣技（斬撃・突き・回転斬り）は振りが速く、振っている間も動けます。最後の一撃が当たった後は、移動の入力ですぐ歩き出せます。
- 町の号外記者コトリに話しかけると、すぐに最新の号外が開きます（閉じると町に戻ります）。まだ号外が 1 枚もないときだけ、コトリのひとことが出ます。号外は生成りの紙に印刷した見た目になりました（前は暗い紙で文字が読めませんでした）。
- 町の青い案内線（ナビ）は常に表示されます（切り替えはありません）。
- タイトルの「つづきからはじめる」は、全部のデータが届いてから始まります（2 回目からはブラウザに残っている分を使うのですぐです）。

## 軽さ

- スマホ・タブレット・高解像度の画面では、描画を横 1920 ピクセルまでに抑えて拡大表示します（文字は 1600×900 基準なのでくっきりのまま）。ブラウザ版では 3D のアンチエイリアスを切っています。
- 画面内コントローラーは、押されたときなど変化があったときだけ描き直します。
- モンスターの攻撃エフェクトは、横長の絵（最大 約 14000 ピクセル）を 4096 ピクセル以下に切り分けて使います（ブラウザやスマホが受け付けない大きさの絵を使わないため）。その階にいないモンスターのエフェクトはメモリから外します。

キーボード：町は E アクション / BackSpace 戻る / M 地図 / I 装備・道具 / Esc メニュー、ダンジョンは J 斬撃 / K 突き / L 回転斬り / U 奥義 / Space 回避 / Q 回復 / F 護符 / E 調べる / M 地図 / I 装備・道具 / Esc メニュー。
