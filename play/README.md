# プリンワールド ブラウザ版 0.12.12（テスト用）

https://purinyogurtworld-design.github.io/punyan/play/ を開くと遊べます。

- パソコンの Chrome か Edge でどうぞ。
- 最初に読み込むのは約 22 MB（エンジン・タイトル・名前入力・章選択）だけです。ふつうの回線なら 10 秒ほどでタイトルが出ます。
- 残りのデータは、タイトルが出た瞬間から裏で読み込みます（画面には出しません）。物語で先に使う順に並べてあるので、第一章が始まってもそのまま進めます。回線がとても遅くて間に合わないときだけ、右下に「つづきを準備しています…」が少し出ます。
- 操作表示はコントローラー（PlayStation の ×○□△ など、Xbox のパッドならABXY）が基本です。タイトルの「設定 → ボタン表示」でキーボード表示にも切り替えられます。
- メニュー・会話・街歩き・攻撃まで、ゲームパッドだけで遊べます（キーボード・マウスも使えます）。
- 冒険の記録はそのブラウザに残ります（別のブラウザやPCには引き継がれません）。

## ゲームパッドの操作

| 場面 | ボタン |
|---|---|
| メニュー | 十字キー・左スティック 選択 / × 決定 / ○ 戻る / L1・R1 ページ |
| 会話 | × 次へ / 十字キー← 読み返す / ○ 中断 |
| 町 | 左スティック 移動 / × 調べる・話す / □ 日誌 / △ 号外 / OPTIONS メニュー |
| 戦闘 | □ 斬撃 / △ 突き / R1 回転斬り / R2 奥義 / ○ 回避 / L1 回復 / L2 護符 / タッチパッド 地図 / OPTIONS 冒険メニュー |
| 牧場 | L1・R1 牧区 / □ 同行させる / △ 預ける / × 調べる / ○ 戻る |
